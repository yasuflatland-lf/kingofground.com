# i18n の約束事

## ロケールと URL

- ロケールは `ja`（デフォルト、URL プレフィックスなし）と `en`（`/en/`）。定義は `src/i18n/config.ts` と `astro.config.ts` の `i18n`。
- ページは `src/pages/[...lang]/` に置く。`lang` パラメータは `undefined` が ja、`'en'` が en で、`localeFromParam()` がロケールに変換する。
- URL は `localePath(locale, '/blogs/')` で作る。文字列連結で `/en/` を付けない。末尾の `/` は `localePath` が補う（`trailingSlash: 'always'`）。

## UI 文言

- UI 文言は `src/i18n/ui.ts` にだけ書く。`.astro` に日本語・英語を直書きしない。
- キーは ja 辞書から型を取るので、en に追加し忘れると `astro check` で落ちる。
- 日付表記は `src/i18n/format.ts` の `formatDate()` を使う。

## 翻訳ペアと言語スイッチャー

- 翻訳ペアは「同じ相対パス」で決まる（`ja/<slug>` と `en/<slug>`）。frontmatter で紐付けない。
- 各ページは `BaseLayout` に `translations`（存在する翻訳の URL パス。自分自身を含む）を渡す。hreflang と言語スイッチャーはこれから作られる。
- 翻訳が無いロケールへは `fallbackPath`（セクションのトップ。ブログなら `/blogs/`）に飛ばす。省略時は `/`。
- 英語版が無いコンテンツの英語ページは生成しない。英語の一覧には英語版のあるエントリだけ並ぶ。

## 見出しの言語属性

- 日本語ページでも欧文だけの見出し（wordmark、大会名）には `lang="en"` を付ける。行間・字間・改行規則は `:lang()` で切り替わる（[design.md](./design.md)）。
